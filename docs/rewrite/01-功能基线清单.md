## 2. 实时推理（核心）

### 2.1 加载与启动
| # | 基线 | 观测点 |
|---|---|---|
| 2.1.1 | `RealtimeEngine` 是唯一门面；`load_model` 失败时 `self.pipeline=None` 后 re-raise（旧模型已卸载） | 二次加载前点开始 → 报未加载模型 |
| 2.1.2 | 模型加载：合成器 `torch.load(weights_only=False)` + `strict=False`（缺键静默）；HuBERT 本地三件套（base/chinese 两变体）；未知 hubert 变体抛 `FeatureExtractionError` | 损坏 .pth → 弹窗 str(e) |
| 2.1.3 | `setup()`：设 `sd.default.device=[in,out]` 全局；校验输入/输出/副输出通道数（不符抛 `AudioDeviceError`）；块参数对齐 10ms 边界 | 非法设备名 → 明确报错 |
| 2.1.4 | 预热 30 次 + CUDA Graph 捕获（HuBERT/RMVPE/合成器全链路）；warmup 失败仅 warning 不断流 | 首次点开始无卡顿 |
| 2.1.5 | 模型缓存 LRU：hubert=2 / rmvpe=1 / fcpe=1 / 合成器=2 | 热切换第 3 个合成器 → 第 1 个卸载 |

| 2.2.2 | 帧率约定 100fps（`zc=sr//100`）；48k↔16k 双重采样（torchaudio Resample） | — |
