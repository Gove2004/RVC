## 4. 删除项清单

| 删除项 | 理由 |
|---|---|
| `pytest.ini` + 手工测试清单 | 改 unittest 自动发现（Q3 拍板，不引依赖） |
| `save_state.json` 的 `models` 字段 | 未使用的冗余状态（阶段零拍板） |
| no-op `clip_grad_value_` 调用 | 梯度值裁剪无效果（A1） |
| `RMVPE` STFT 死类、`resample_kernel` 死字段、`n_gru` 不可达分支、`attn=None` 残留 | 死代码（A5） |
| `EngineState` 的 prefetch/AudioProcessor/sola_buffer | 死路径与错位职责（A2/A7） |
| `_loader.FFMPEG_EXE` 进程内重定向通道 | 隐式全局状态，改显式传参（D4） |
| WEIGHTS_DIR monkey-patch 通道 | 隐式全局状态，多实例污染（S8） |
| autodl import 时 `os.chdir` | import 副作用，移入 `main()`（Q6） |
| `RealtimeEngine` 旧门面名 | 改名（Q2），arch guard 有残留哨兵 |
| 旧 `__pycache__`（25 目录 896KB） | 编译缓存（untracked，S11） |

## 6. 并发缺陷修复清单

| 缺陷 | 现象 | 修复 |
|---|---|---|
| P0-11 | pinned memory 异步 DMA 竞态，输入被下一块污染（金标准 NaN 根因之一） | 输入同步上传（in_pin→input_gpu），S7 |
| P0-12 | 双 CUDA Stream + fp16 非同步语义 = 未定义行为，随机 NaN | HuBERT/RMVPE 串行化（方案 A，实测增量 ≈0.3ms/块），S6 |
| P0-13 | 同进程双引擎实例互相污染全局状态 | 实证修复：双引擎 4/4 用例通过，S7 |
| P0-14 | 块尾缺同步，D2H 读到未完成数据 | D2H 改本同步（synchronize）关闭，S7 |
