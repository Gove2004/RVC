## 3. 实时推理链（行为级）

| # | 行为 | 验证 |
|---|---|---|
| 3.1 | 处理块长 = block_time×sr，所有采样数对齐 10ms 边界；输出块长与输入块长一致（SOLA 对齐后） | [T] dsp 层 / [M] 端到端 |
| 3.2 | F0 提取：method=rmvpe（assets/rmvpe/rmvpe.pt）/ fcpe（torchfcpe 内置权重）；阈值 rmvpe=0.05（用户可调）、fcpe=0.05；FCPE 换 confidence 阈值会重建 CUDA Graph ⚠ | [N] |
| 3.3 | 音域映射：MIDI 半音尺度线性映射，线性外推不钳制；参数无效原样返回；常量 tensor 按(参数,设备)缓存上限 128 | [T] |
| 3.4 | F0 后处理顺序：音域映射 → 因果中值滤波 kernel=3（replicate 左填充；清音保持 0，浊音被滤成 0 恢复原值）→ HTK mel 归一到 [1,255] 离散 bins（0=UV；NaN/inf 归清音） | [T] |
| 3.5 | 共振峰：formant 经重采样实现音高偏移，pitchf 乘 return_length2/return_length 缩放；formant 因子 = 2^(f/12) | [M] |
| 3.6 | 预处理滚动缓冲：48k/16k 双缓冲，只重采样新块，丢弃前 160 样本防特征漂移 ⚠ torchaudio Resample 边缘延迟假设 | [M] |
| 3.7 | 合成器保留原版魔数：噪声尺度 0.66666、flow 24 帧上下文 ⚠；v2 768 维，pth 权重键名与 18 元 config 顺序与原版 RVC 完全兼容（可加载官方模型） | [N] 与真实模型互操作 |
| 3.8 | RMS 混合：`converted*(r1/r2)^(1-rms_mix)`，rms_mix≥1 跳过；SOLA：归一化互相关找 offset（只除当前块能量平方根）+ sin² 交叉淡化，禁止跨块 offset 平滑；⚠ SOLA 返回值与 infer 共享存储被原地改写 | [T] |
| 3.9 | CUDA Graph：按签名 LRU 上限 8（env `RVC_CUDA_GRAPH_MAX_CACHE`）；预热 30 块静音完成捕获；清除必须 gc+sync+empty_cache ⚠；探测开关 env `RVC_CUDA_GRAPH=1` | [M] |
| 3.10 | 设备：硬编码 `cuda:0` + `is_half=True`，无 CUDA 直接崩（无 CPU 回退）——现状行为，保持 | [N] |
| 3.11 | 模型缓存：hubert LRU=2、rmvpe=1、fcpe=1、synthesizer=2，仅 LRU 淘汰无 mtime 校验；全局单例跨引擎共享 | [N] |
| 3.12 | HuBERT：HuggingFace 本地目录三件套加载，变体 base/chinese；GUI 无控制台时 stdout/stderr 换 devnull（全局副作用）⚠ | [M] |
