## 2. 验证体系

三层自证，每步提交前必须全过：

1. **单元测试**（65 例，unittest 自动发现）：`python -m tests.run_tests`
2. **离线金标准**（旧代码采集参考输出，STFT 谱差度量，容差 mean ≤0.5dB / p99 ≤3.0dB）：`scripts/golden.py verify`
3. **autodl 管道金标准**（stdin 喂答案，逐行输出归一化 diff + 退出码）：内含于单测

谱度量说明：`spectral_db_diff` = STFT 幅度谱取 dB（40dB 能量下限钳制）后逐点差。选择理由：旧代码 SOLA 逐块拼接的相位混沌，逐点波形对比数学上不可复现；谱差对拼接对齐不敏感、对音色/谱包络敏感，是该场景的正确度量。

## 7. 用户可感知变化标注

1. **spec 缓存目录迁移**（A6）：训练实验目录内 `{exp}/0_gt_wavs/` 不再出现缓存文件，统一在 `{exp}/spec_cache/`。缓存失效语义不变。
2. **无兼容层**：旧版配置/接口不兼容（重写硬约束）。checkpoint 格式保持互操作（S8 真实模型加载验证）。
3. **F0 默认值 UI 漂移修复**：此前 UI 默认亮 FCPE 而配置默认 rmvpe；现 UI 按 params 选中。用户未改动过该设置则行为不变。
4. **`load_checkpoint` 缺键告警**：静默跳过改为 warning，便于发现损坏 checkpoint。

## 8. 已知限制

- offline_b 的 p99 值受 SOLA 拼接抖动影响，复跑在 2.0–2.8dB 间波动（容差 3.0dB 内，历次 PASS）
- offscreen 环境下托盘初始化必然失败并弹模态框（设计行为），自动化测试以桩绕过；真机不受影响
- 未兼容 CPU 设备（阶段零拍板）；`io/audio_file.py` 保留模块全局通道到 S9 后已由显式传参取代，全局变量仅作默认值来源
