## 三、内部结构改动（对外行为不变）

| # | 旧机制 | 新机制 | 理由 |
|---|---|---|---|
| A1 | 环境变量 `RVC_CUDA_GRAPH` 跨模块开关 | `RuntimeOptions` 显式对象，`configure_cuda_graph()` 唯一写入口 | 显式优于隐式；配置语义集中在 device.py |
| A2 | 散落的 graph 清理（gc+sync+empty_cache 各处手写） | `purge_cuda_graphs()` 单入口：逐条目取锁（无在途回放）+ 统一跑一次 gc+sync+empty_cache | 消除旧图/新图地址竞争类 bug 的温床 |
| A3 | tracker.py 魔法数字 4（RMVPE mel 边缘帧） | `RMVPE_F0_HEAD/TAIL_MARGIN_FRAMES` 命名常量 + 推导注释 + 逐元素等价测试 | 未文档化行为显式化 |
| A4 | sessions.py 访问 cache 私有属性 `_synthesizer.values()` | 公共 `synthesizer_bundles()` 快照 API | 依赖单向、封装 |
| A5 | synthesizer 子类"先建 256 维 enc_p 再 del 重建 768 维" | 基类 `phone_dim` 参数，一步构造 | 消除浪费性双构造；权重键不变（strict 往返测试锁定） |
| A6 | `sounddevice._terminate()/_initialize()` 裸调 | `_rescan_portaudio_devices()` 命名封装 + 版本前提注释 | 私有 API 依赖单点化 |
| A7 | GUI bindings/window 大量 `hasattr` 探测 | 删除（所有控件无条件构建），缺控件立即 AttributeError | 错误显式化，静默跳过是最坏的失败方式 |
| A8 | `slice_segments` 等 VITS 数值块 | 不动，加锁定注释（AL-4） | 数值路径与已导出权重一致性 > 局部优雅 |
| A9 | wav_file.py 引用不存在的 wav_io.py 的过时 docstring | 修正为真实分工描述 | 文档说谎比没有文档更糟 |
